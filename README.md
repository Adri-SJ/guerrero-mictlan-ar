# Guerrero del Mictlán AR

Filtro facial de Realidad Aumentada inspirado en Día de Muertos y una estética de guerrero del inframundo.

## Concepto

La experiencia transforma el rostro del usuario mediante una máscara completa con acabado oscuro/obsidiana, detalles rojos y dorados, más una corona superior tipo guerrero.

## Interacciones

- Abrir la boca: activa un resplandor rojo intenso.
- Parpadear: activa un destello energético.
- Levantar las cejas: activa el sello dorado y expande el tocado.

## Tecnologías

- HTML, CSS y JavaScript
- Three.js
- MindAR Face Tracking
- MediaPipe Face Mesh
- Web Audio API
- Vercel

## Estado

Primera versión funcional preparada para despliegue y pruebas en móvil.
