# Calavera de Cempasúchil AR

Filtro facial de Realidad Aumentada inspirado en el maquillaje tradicional de Día de Muertos y el cempasúchil.

## Concepto

La experiencia transforma el rostro del usuario con una calavera clara, ojos florales de cempasúchil, nariz de calavera, dientes decorativos y ornamentos de color.

## Interacciones

- Abrir la boca: activa un resplandor rojo intenso.
- Parpadear: activa un destello energético.
- Levantar las cejas: activa el sello dorado y expande el tocado.

## Tecnologías

- HTML, CSS y JavaScript
- Three.js
- MindAR Face Tracking
- MediaPipe Face Mesh
- Web Audio API
- Vercel

## Estado

Primera versión funcional preparada para despliegue y pruebas en móvil.
